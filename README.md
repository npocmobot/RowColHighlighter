# RowColHighlighter — надстройка Excel

Надстройка для Microsoft Excel 2021 (Windows), которая автоматически подсвечивает строку и столбец активной ячейки. Помогает не терять взглядом нужные данные в больших таблицах.

## Возможности

- Автоматическая подсветка строки и столбца при выделении любой ячейки
- Исходная заливка ячеек запоминается и полностью восстанавливается при переходе на другую ячейку
- Перед сохранением файла подсветка автоматически снимается, поэтому жёлтый цвет не сохраняется в документе. Сразу после сохранения подсветка возвращается
- Кнопка включения и выключения на панели быстрого доступа
- Запоминание состояния (вкл/выкл) между запусками Excel
- Автоматическое восстановление стандартной сетки при выключении подсветки
- Работает во всех открытых книгах без дополнительных макросов
- Подсветка обновляется при переключении между листами и книгами

## Как это работает

Надстройка написана на VBA и подключается как стандартная надстройка `.xlam`.

**Технические детали:**

- Используется перехват события `Application.SheetSelectionChange` через класс с `WithEvents`
- Исходные цвета ячеек сохраняются в объекты `Dictionary` (ключ — адрес ячейки, значение — исходный цвет)
- При смене выделения старые цвета восстанавливаются, новые запоминаются
- При сохранении файла (`WorkbookBeforeSave`) подсветка снимается, после сохранения (`OnTime`) — возвращается
- Состояние включения/выключения хранится в реестре Windows: `HKEY_CURRENT_USER\Software\RowColHighlighter`
- Сетка восстанавливается программно: проверяются все 6 типов границ ячейки, если все пустые — рисуется стандартная серая линия `RGB(217, 217, 217)`

**Известная особенность:**

У ячеек, у которых не было явно заданных границ (только стандартная сетка листа), сетка может пропасть после снятия подсветки. Это ограничение Excel: при программной установке `Interior.Color` стандартная сетка сбрасывается. Надстройка автоматически восстанавливает сетку при выключении и при сохранении файла.

## Установка

1. Скачайте `RowColHighlighter.xlam` со [страницы релизов](https://github.com/npocmobot/RowColHighlighter/releases/latest)
2. **Важно! Снимите блокировку с файла:**
   - Нажмите правой кнопкой мыши на скачанный файл `RowColHighlighter.xlam`
   - Выберите **«Свойства»**
   - Внизу окна найдите раздел **«Безопасность»**
   - Если есть предупреждение «Этот файл получен с другого компьютера...», поставьте галочку **«Разблокировать»**
   - Нажмите **«Применить»**, затем **«ОК»**
   - Если такого предупреждения нет — просто закройте окно свойств
3. Откройте Excel
4. Нажмите **Файл**, затем **Параметры**
5. Выберите **Центр управления безопасностью**
6. Нажмите **Параметры центра управления безопасностью**
7. Выберите **Параметры макросов**
8. Выберите **Включить все макросы**
9. Поставьте галочку **Доверять доступ к объектной модели проектов VBA**
10. Нажмите ОК, затем ещё раз ОК
11. Нажмите **Файл**, затем **Параметры**, затем **Надстройки**
12. Внизу в списке «Управление» выберите **Надстройки Excel**
13. Нажмите **Перейти**
14. Нажмите **Обзор**
15. Найдите и выберите файл `RowColHighlighter.xlam`
16. Нажмите ОК
17. Убедитесь, что стоит галочка напротив **RowColHighlighter**
18. Нажмите ОК
19. Закройте Excel и откройте заново

## Использование

- Выделите ячейку — строка и столбец подсветятся жёлтым цветом
- Перейдите на другую ячейку — старая подсветка исчезнет, новая появится
- На панели быстрого доступа (слева вверху) появится кнопка **Подсветка ВКЛ/ВЫКЛ**
- Одно нажатие кнопки — подсветка выключается, сетка восстанавливается
- Повторное нажатие — подсветка включается снова
- Состояние запоминается между запусками Excel

**Если кнопка не появилась:**

- Нажмите стрелочку вниз в конце панели быстрого доступа
- Выберите **Другие команды**
- В списке «Выбрать команды из» выберите **Макросы**
- Найдите **ToggleHighlight**, выделите его
- Нажмите **Добавить**, затем ОК

## Настройка

### Изменение цвета подсветки

1. Нажмите `Alt + F11`
2. В левом окне найдите **VBAProject (RowColHighlighter.xlam)**
3. Разверните папку **Class Modules**
4. Дважды щёлкните **AppEventClass**
5. Найдите строку `Private Const HIGHLIGHT_COLOR As Long = &HB4FFFF`
6. Замените на нужный цвет из таблицы ниже
7. Нажмите `Ctrl + S`, закройте редактор, перезапустите Excel

**Готовые цвета:**

| Цвет | Код |
|------|-----|
| Светло-жёлтый (по умолчанию) | `&HB4FFFF` |
| Светло-голубой | `&HFFFFCC` |
| Светло-зелёный | `&HC6EFCE` |
| Светло-розовый | `&HD8E4F0` |
| Светло-серый | `&HE0E0E0` |
| Светло-оранжевый | `&HC0E0FF` |
| Светло-сиреневый | `&HFFC0FF` |

### Изменение цвета восстанавливаемой сетки

1. Нажмите `Alt + F11`
2. В левом окне найдите **VBAProject (RowColHighlighter.xlam)**
3. Разверните папку **Modules**
4. Дважды щёлкните **Module1**
5. Найдите `RGB(217, 217, 217)` (встречается в двух местах)
6. Замените на нужный цвет, например `RGB(200, 200, 200)`
7. Нажмите `Ctrl + S`, закройте редактор, перезапустите Excel

## Удаление

### Временно отключить

- Нажмите **Файл**, затем **Параметры**, затем **Надстройки**
- В списке «Управление» выберите **Надстройки Excel**, нажмите **Перейти**
- Снимите галочку с **RowColHighlighter**, нажмите ОК

### Полностью удалить

- Выполните отключение как описано выше
- Нажмите `Win + R`, введите `%APPDATA%\Microsoft\AddIns`, нажмите Enter
- Удалите файл **RowColHighlighter.xlam**
- Для очистки сохранённого состояния:
  - Нажмите `Win + R`, введите `regedit`, нажмите Enter
  - Перейдите по пути: `HKEY_CURRENT_USER\Software\RowColHighlighter`
  - Удалите папку `RowColHighlighter`

## Часто задаваемые вопросы

**Почему пропадает сетка?**

При программной установке цвета заливки Excel сбрасывает стандартную сетку листа. Надстройка автоматически восстанавливает сетку при выключении подсветки и при сохранении файла. Если сетка пропала не везде — нажмите кнопку выключения подсветки ещё раз.

**Сохраняется ли жёлтый цвет в файл?**

Нет. Надстройка перехватывает событие сохранения и снимает подсветку до записи файла на диск. После сохранения подсветка возвращается.

**Работает ли на Excel 2016, 2019, Microsoft 365?**

Разработана для Excel 2021. На других версиях для Windows, вероятно, работает. На Excel для Mac не работает.

**Работает ли на защищённых листах?**

Нет. Если лист защищён паролем, снимите защиту для использования надстройки.

**Замедляет ли работу Excel?**

На таблицах до 1000 строк замедление незаметно. На очень больших таблицах возможна небольшая задержка при смене ячейки.

**Можно ли использовать в коммерческих целях?**

Да. Надстройка бесплатна для личного и коммерческого использования.

## Перенос на другой компьютер

1. На старом компьютере нажмите `Win + R`, введите `%APPDATA%\Microsoft\AddIns`, нажмите Enter
2. Скопируйте файл **RowColHighlighter.xlam** на флешку
3. На новом компьютере скопируйте файл в любую папку (например, на рабочий стол)
4. **Важно! Снимите блокировку с файла:**
   - Нажмите правой кнопкой мыши на файл `RowColHighlighter.xlam`
   - Выберите **«Свойства»**
   - Если есть предупреждение «Этот файл получен с другого компьютера...», поставьте галочку **«Разблокировать»**
   - Нажмите **«Применить»**, затем **«ОК»**
5. Нажмите `Win + R`, введите `%APPDATA%\Microsoft\AddIns`, нажмите Enter
6. Скопируйте файл **RowColHighlighter.xlam** в эту папку
7. Настройте безопасность Excel (см. раздел «Установка», пункты 4–10)
8. Подключите надстройку (см. раздел «Установка», пункты 11–19)
9. Перезапустите Excel

Состояние (вкл/выкл) хранится в реестре Windows и не переносится. На новом компьютере надстройка запустится во включённом состоянии.
